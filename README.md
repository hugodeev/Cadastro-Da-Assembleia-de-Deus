# Landing Page – Encontro de Casais

Este é um projeto de landing page desenvolvido especialmente para o **Encontro de Casais da igreja**, com o objetivo de facilitar o cadastro dos participantes e oferecer todas as informações necessárias de forma prática e acolhedora.

## 🔗 Acesse o projeto
👉 [Visualizar Landing Page](https://hugodeev.github.io/Cadastro-Da-Assembleia-de-Deus/)  

---

## 📌 Funcionalidades

- Página de boas-vindas com imagem e descrição do evento
- Formulário de cadastro com campos para:
  - Nome do esposo
  - Nome da esposa
  - Contato (WhatsApp)
  - Cidade
- Informações sobre a taxa de participação
- QR Code para pagamento via Pix
- Botão de envio de cadastro via WhatsApp
- Layout responsivo

---

## 🛠 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript Vanilla**

---

## 💡 Objetivo do projeto

O objetivo principal foi desenvolver uma página simples, elegante e funcional para divulgar o evento e facilitar o cadastro dos casais interessados em participar.  
Além disso, foi uma ótima oportunidade de praticar front-end e aplicar conceitos de usabilidade.
